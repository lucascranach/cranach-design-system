# cranach-image-tools

Interner Bild-Browser in PHP mit Plain CSS. Schritt 7 der [Migration](?path=/docs/migration-übersicht--docs), zusammen mit cda-orga, im Umfang „light“: Tokens und Grundstyles. Die Variablen stammen von cranach-grafiken-gatsby ab; die Grundgröße ist 1rem (16 px).

Die Seite ist **dunkel**. Einbinden mit festem dunklen Theme:

```html
<html lang="de" data-theme="dark">
…
<link rel="stylesheet" href="/design-system/X.Y.Z/cranach.css">
```

Die Werte unten sind deshalb die des dunklen Themes. Alle Variablen stehen in `styles/variables.css`. „Nicht verwendet“ heißt: in keiner CSS-Datei, `index.html` oder `main.js` gefunden – diese Variablen können einfach entfallen.

## Beim Umstellen beachten

- **Resets entfernen:** `* { margin: 0; padding: 0 }` und `header, footer, section { float: left }` in `reset.css` sowie `* { box-sizing: content-box }` in `main.css` gewinnen gegen die Komponenten und nehmen Button und Eingabefeld die Innenabstände. `reset.css` nutzt außerdem `//`-Kommentare, die es in CSS nicht gibt.
- **`outline: none`** am Suchfeld (`components.css`) löschen.
- **Kaputte Stellen:** `@import './fonts'` zeigt auf eine fehlende Datei; `-var(--l + $xs)` und `var(--border-stroke-weight $accent)` in `main.css` sind Sass-Reste und ungültig. Alle `@import` stehen ohne `.css`-Endung.
- **Sichtbare Änderung:** Weil Schrift und Icons heute ohne `@font-face` geladen werden, sehen sie mit `cranach.css` erstmals überall gleich aus.
