# Projektkomponenten

Komponenten, die es nur in einem Projekt gibt. Sie gehören **nicht** zum Designsystem und stecken nicht in `cranach.css`. Sie stehen hier, damit niemand eine Komponente neu baut, die ein anderes Projekt schon hat (ADR 0020).

## So geht es

1. **Vor dem Bauen nachsehen:** Gibt es die Komponente unter [Komponenten](?path=/docs/komponenten-button--docs) im Designsystem? Steht sie hier im Katalog?
2. **Steht sie hier,** ist das neue Projekt das zweite. Die Komponente kommt ins Designsystem – als eigener Roadmap-Schritt, mit der vorhandenen Umsetzung als Vorlage – statt ein zweites Mal gebaut zu werden.
3. **Gibt es sie nirgends,** wird sie im Projekt gebaut, mit den Tokens des Designsystems und ohne Präfix `cda-`. Im selben Zug kommt hier ein Eintrag dazu – siehe [Eintrag ergänzen](#eintrag-ergänzen).

Stand: Durchsicht der Projekte am 11.11.2026. Pfade relativ zum jeweiligen Projekt.

## Nur in einem Projekt

Ein Klick auf das Foto zeigt es groß, „Ansehen“ öffnet eine Seite, auf der die Komponente vorkommt, „Code“ die Datei auf GitHub. Fehlt ein Foto, steht der Grund in der Kachel. Mit der neuen Website cranach-kirby werden voraussichtlich Seitenblättern, Teaser und Brotkrumen ein zweites Projekt finden.

## Eintrag ergänzen

Die Einträge stehen in `stories/projektkomponenten.json`, je Komponente ein Block mit Name, Projekt, Zweck, Fundort, Code-Link und – wenn öffentlich – Live-Seite. Das Foto entsteht so:

- **Öffentliche Seite:** unter `photo` Adresse und CSS-Selektor des Elements eintragen, dann `npm run catalog:photos -- <Name>`. Das Skript fotografiert das Element in einem unsichtbaren Chrome, legt es als WebP unter `stories/assets/projektkomponenten/` ab und setzt das Datum. Braucht lokal Google Chrome und `cwebp` (`brew install webp`).
- **Interne Seite oder lokaler Prototyp:** Bildschirmfoto von Hand als WebP mit höchstens 1200 px Breite ablegen, Dateinamen unter `image` und das Datum unter `shot` eintragen.
- **Kein Foto möglich:** Grund unter `noPhoto` eintragen, etwa „erscheint erst beim Scrollen“.

Ändert sich eine Komponente im Projekt, das Foto neu aufnehmen.
