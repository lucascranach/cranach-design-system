# Cluster

Kinder nebeneinander, die bei Platzmangel in die nächste Zeile umbrechen – für Buttons, Filter, Schlagworte. Die Breite des Rahmens lässt sich an der Ecke unten rechts ziehen.

```html
<ul class="cda-l-cluster" role="list">
  <li><button type="button" class="cda-button">Malerei</button></li>
  <li><button type="button" class="cda-button">Zeichnung</button></li>
  …
</ul>
```

<Canvas of={Cluster.Schlagworte} />

## Einstellen

| Variable | Standard | Wirkung |
|---|---|---|
| `--cda-l-space` | `--cda-space-s` (12 px) | Abstand waagerecht und senkrecht |

So lassen sich die Werte setzen, in dieser Reihenfolge (ADR 0021):

1. **Abstand über eine Utility** – eine Klasse je Abstands-Token, siehe [Utilities](?path=/docs/utilities--docs): `class="cda-l-stack cda-u-space-xl"`.
2. **Breiten und Sonderfälle in einer Regel im Projekt-CSS:** `.ergebnisse { --cda-l-space: var(--cda-space-xl); }`.
3. **`style`-Attribut nur als Notlösung** – Projekte mit strenger Content-Security-Policy verbieten es, und Tippfehler fallen nicht auf.

## Hinweise

- Die Kinder sind senkrecht mittig ausgerichtet, damit Buttons und Text unterschiedlicher Höhe auf einer Linie stehen.
- Für eine Reihe, die nie umbrechen soll, ist der Cluster nicht gedacht; dafür reicht `display: flex` im Projekt.
