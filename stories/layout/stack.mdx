# Stack

Kinder untereinander mit gleichem Abstand. Das häufigste Layout: für Abschnitte einer Seite, den Inhalt einer Karte, Formularfelder. In CUBE CSS heißt es „Flow“, in Every Layout „Stack“.

```html
<div class="cda-l-stack">
  <h2>…</h2>
  <p>…</p>
  <button class="cda-button">…</button>
</div>
```

<Canvas of={Stack.Standard} />

## Einstellen

| Variable | Standard | Wirkung |
|---|---|---|
| `--cda-l-space` | `--cda-space-m` (16 px) | Abstand zwischen den Kindern |

Wie die Werte gesetzt werden, steht in der [Übersicht](?path=/docs/layout-übersicht--docs).

```html
<div class="cda-l-stack cda-u-space-xl">…</div>
```

<Canvas of={Stack.GroesserAbstand} />

## Hinweise

- Der Abstand sitzt oben am zweiten und jedem weiteren Kind. Eigene Außenabstände der Kinder oben und unten entfallen; so addieren sich keine Abstände.
