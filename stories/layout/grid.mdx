# Grid

Raster mit einer Mindestbreite je Spalte; es passen so viele Spalten hinein, wie Platz ist. Auf schmalen Bildschirmen wird eine Spalte nie breiter als der verfügbare Platz. Standard ist die Mindestbreite der [Werk-Karte](?path=/docs/komponenten-werk-karte--docs) – das Grid ersetzt das frühere `.cda-card-grid`. Zum Ausprobieren die Breite an der Ecke unten rechts ziehen.

```html
<ul class="cda-l-grid" role="list">
  <li>…</li>
  <li>…</li>
</ul>
```

<Canvas of={Grid.Standard} />

## Einstellen

| Variable | Standard | Wirkung |
|---|---|---|
| `--cda-l-min` | `--cda-size-card-min` (256 px) | Mindestbreite einer Spalte |
| `--cda-l-space` | `--cda-space-s` (12 px) | Abstand zwischen den Kacheln |

Wie die Werte gesetzt werden, steht in der [Übersicht](?path=/docs/layout-übersicht--docs).

## Klein

Für die kleine Kachelansicht der Werk-Karte, nur mit Bildern: Mindestbreite `size.card.min-small` (128 px), Abstand `2xs` (4 px).

```html
<ul class="cda-l-grid cda-l-grid--small" role="list">
  …
</ul>
```
