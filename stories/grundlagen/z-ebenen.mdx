# z-Ebenen

Statt freier Zahlen wie 99999 gibt es benannte Ebenen. Die Werte stammen unverändert aus dem Bolt Design System und sind um zwei Ebenen ergänzt (ADR 0011).

```css
.kopfzeile {
  position: sticky;
  inset-block-start: 0;
  z-index: var(--cda-z-nav-fixed);
}
```

## Regeln

- **Nur über Tokens.** Feste z-Index-Werte im Code vermeiden.
- **Dialoge** bevorzugt mit `<dialog>` oder der Popover-API: Sie liegen im Top-Layer und brauchen keinen z-Index.
- **Drawer** verwenden `modal-bg` für die Abdunkelung und `modal` für den Inhalt.
- **toast** liegt über `modal`, damit Benachrichtigungen auch bei offenem Dialog oder Bildviewer sichtbar sind.
- **skip-link** liegt über allem: Ein fokussiertes Element darf nicht verdeckt sein (WCAG 2.4.11).
- Wie bei Bolt liegt `tooltip` unter `nav-fixed`: Tooltips im Inhalt werden vom fixierten Header verdeckt.
