# Abstände

Abstände folgen einem **4-px-Raster** mit T-Shirt-Namen. Für Abschnitte gibt es drei fließende Abstände, die mit der Fensterbreite wachsen (ADR 0010).

```css
.karte {
  padding: var(--cda-space-m);
  gap: var(--cda-space-xs);
}

.abschnitt {
  padding-block: var(--cda-space-fluid-l);
}
```

## Breakpoints

Kachel-Raster passen sich besser fließend an (`repeat(auto-fill, minmax(…))` oder Container Queries) als über Breakpoints. Custom Properties lassen sich in `@media` nicht verwenden; dafür gibt es `custom-media.css`.

```css
@import "@lucascranach/design-system/custom-media.css";

@media (--cda-md) {
  /* ab 768 px */
}
```
